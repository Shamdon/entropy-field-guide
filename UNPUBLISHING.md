# How to unpublish the site

Unpublishing removes the public GitHub Pages deployment. It does not delete this repository, its history, or any source files.

## From an iPhone

GitHub's iPhone app may not show every Pages control. If **Pages** is missing, open this repository in Safari, sign in, and use the desktop website controls.

1. Open the repository.
2. Open **Settings**.
3. Open **Pages** in the **Code and automation** section.
4. Find the message showing that the site is live.
5. Open the three-dot menu beside that message.
6. Choose **Unpublish site** and confirm.

The repository remains intact. You can publish it again later by returning to **Settings → Pages** and selecting **main** plus **/docs** as the publishing source.

## Important distinction

Making the repository private is not the same as unpublishing the Pages site, and availability depends on your GitHub plan. Use the Pages **Unpublish site** control when you specifically want the website taken offline.
